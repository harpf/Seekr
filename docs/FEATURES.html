Feature Catalogue · Self-hosted Document Intelligence

Seekr

Crawl, extract, index and find every document you own — entirely on your own infrastructure.

A FastAPI + SQLite FTS5 search platform with optional local LLM assistance via Ollama. No cloud, no telemetry, no data leaving the building. This sheet catalogues every capability present on main today.

01

Ingestion & Extraction

The pipeline that turns files on disk into searchable, structured content blocks.

Filesystem crawler

crawler

Recursively walks source paths with symlink, hidden-file, temp-file and glob exclusion rules, honouring per-file size limits.

Multi-format extractors

extractors

.pdf (pypdf + Tesseract OCR), .docx, .pptx, legacy .doc/.ppt (antiword/catppt), .txt and .md — each producing typed content blocks.

Plugin extractor API

extensible

Add new file types without forking: register via Python entry points or a drop-in plugins/ directory. Versioned contract, conflict guards, full per-plugin error isolation.

Registry-aware crawling

registry

The crawler gates on the live extractor registry, so any built-in or plugin file type flows end-to-end once enabled in config.

Optional OCR pipeline

ocr

Tesseract-backed OCR for scanned PDFs and image content, with configurable language packs (eng/deu shipped).

Incremental indexing

sha-256

Files are fingerprinted by SHA-256 + mtime; unchanged documents are skipped, so re-runs only re-extract what actually changed.

Authenticated upload

/api/upload

Drag-and-drop upload with extension allow-list, libmagic magic-byte sniffing, path-traversal containment and an 8 KB metadata cap.

Duplicate detection

/api/documents/duplicates

Surface exact (hash) and near-duplicate documents and remove redundant copies from a review view.

Scheduled re-indexing

scheduler

Optional cron-style periodic crawl driven by the persistent job queue — no manual trigger required.

02

Search

Full-text keyword search blended with optional local vector retrieval.

SQLite FTS5 full-text

/api/search

BM25-ranked search supporting AND / OR, exact phrases, prefix (maint*), and negation (-draft).

Hybrid semantic search

embeddings

Local embeddings (Ollama / sentence-transformers) stored in a vector table and fused with BM25 via reciprocal-rank fusion for hybrid ranking.

Embedding backfill job

/api/index/embeddings/start

Vectors are populated by a dedicated backfill job, keeping keyword-only search a first-class low-resource mode.

Faceted filters

filters

Narrow by file type, path prefix, block type (page/paragraph/table/slide), modification-date range and tag.

Snippet highlighting

highlight

Matched terms are highlighted in context-aware snippets with source and metadata shown per result.

Result pagination

limit/offset

Offset paging with a “load more” flow instead of a hard result cap.

Graceful FTS errors

resilient

Unmatched quotes and malformed queries return a friendly “check your syntax” message rather than a 500.

Search history & saved searches

/api/search/saved

Per-user server-side history and named saved searches that restore the full query plus its filters.

Browsable tag cloud

tags

A clickable tag cloud above results filters the index instantly by any label you have applied.

03

Local AI & LLM

Optional Ollama-powered assistance — strictly local, validated, and auditable.

AI filing suggestions

all users

After upload, the model proposes a destination folder, tags and reasoning; apply to move & re-index, or dismiss.

RAG summarisation

/api/ai/summarize

Summarise the top results with citations back to source blocks — synchronous and ACL-inheriting.

Folder-structure suggestions

admin

Analyses the whole index and proposes an optimal folder taxonomy for your collection.

AI reorganizer

admin

Batch-analyses documents and proposes bulk moves, run as a tracked background job.

Bulk auto-tagging

/api/ai/bulk-tag/start

Extends single-file tag suggestion to a job that tags across the entire index.

Validation & provenance

ai_decisions

Every LLM output is schema-validated before persistence and recorded in an ai_decisions audit row capturing model + prompt.

Model management

admin

Pull, delete and test models; connection check confirms the model actually responds.

Resource-aware tiers

system-info

Reports available RAM / GPU VRAM and recommends a model tier, flagging each library model as ok / warn / too-large.

04

Security & Access Control

Authentication, fine-grained document permissions and a tamper-evident audit trail.

PBKDF2 authentication

/api/login

PBKDF2-HMAC-SHA256 password hashing with username/password rules and an admin/user role model.

Externalised sessions

SessionStore

Sessions live in the database (8-hour idle expiry), surviving restarts; no in-memory auth state.

Login rate limiting

RateLimiter

10 failed attempts per 5-minute window per IP, backed by a persistent store.

Document ACL enforcement

acl

Principals, groups and per-document grants gate every document-returning endpoint, not just search.

Grant / revoke API

/api/acl/grant

Read and write permissions granted or revoked per document or group, with owner assignment on ingest.

Group management

admin

Create groups and assign members; visibility falls back to the public group by default.

Admin audit log

/api/audit

Every state-changing route records an audit entry — who did what, when — never logging secrets.

Configurable CORS

closed by default

Explicit origin allow-list via CORSMiddleware; locked down unless explicitly opened.

05

Jobs & Operations

A durable work queue plus the operational surface to back up, restore and observe the system.

Persistent job queue

JobStore + Worker

Indexing and AI jobs survive restarts via an atomic UPDATE … RETURNING claim that anticipates multiple workers.

Global jobs dashboard

/api/jobs

Owner/admin-scoped view of all jobs with state, progress and retry count in one place.

Cancel & re-enqueue

cooperative

Cancel running jobs at checkpoints and re-enqueue interrupted ones with a click.

Backup & restore

/api/backup

WAL-safe SQLite backups, scheduled snapshots, one-click restore and full data export / import.

In-app update flow

admin

Backup → git pull → rebuild via update.sh, with a final status row and auto-rollback on failed health check.

Health & readiness

/health · /ready

Liveness with no DB hit and a readiness probe (503 until the DB and worker are reachable) for orchestration.

Prometheus metrics

/metrics

Request latency, index throughput, queue depth and job success/fail counts on a private registry, token-guarded.

Structured logging

observability

Central logging config replaces silent exception swallowing with leveled, diagnosable log output.

06

Integrations & API

A versioned REST surface, outbound events and a Home-Assistant-style integration channel.

Versioned REST API

/api/v1/*

Scope-rewrite middleware exposes a stable v1 contract with back-compat, plus a polished OpenAPI / wiki page.

Home-Assistant API

/api/ha/*

Dedicated status, test, search and index endpoints for HA-style integrations, authenticated by API keys.

API key management

/api/ha/keys

Create, list and revoke scoped API keys for headless and machine-to-machine access.

Signed webhooks

/api/webhooks

Outbound HMAC-signed webhooks with an SSRF guard and queue-backed retry; fires an index.completed event.

Delivery inspection

deliveries

Per-webhook delivery history for debugging downstream receivers.

Dependency reporting

/api/system/dependencies

Reports presence of system tools (antiword, tesseract, …) so missing extractors are diagnosable.

07

Deployment & Infrastructure

A hardened, container-first deployment that scales from a single node toward multi-instance.

Docker Compose stack

3 containers

App + Ollama + nginx TLS proxy, wired together with internal-only ports and a single public HTTPS entrypoint.

TLS termination

nginx

Auto-generated self-signed certs from TLS_DOMAIN/TLS_IP, or bring your own PEM chain + key.

Self-service certificates

/api/ssl

Generate or upload an application-layer RSA-2048 cert (custom CN/SANs/validity) from the admin UI.

Network share mounts

admin

Mount SMB and NFS shares through the UI with credential-file handling and remote-path validation.

GPU acceleration

nvidia

Opt-in NVIDIA GPU inference for Ollama via a compose deploy block.

Multi-instance readiness

redis optional

Session and rate-limit state run on SQLite by default or Redis via DOCUMENT_SEARCH_STATE_BACKEND, enabling replicas.

Hardened container

non-root

Runs as a dedicated non-root user with pinned security-sensitive dependencies and subprocess timeouts.

CI quality gate

github actions

Every push/PR runs ruff check (gating) and pytest, with informational mypy.

08

Web Interface & UX

A clean vanilla-JS frontend with in-browser preview, theming and per-user preferences.

Vanilla-JS web UI

no build step

Jinja2 templates and a token-based CSS design system across Search, Ingest, Config, Jobs and Wiki views.

In-browser preview

/api/files/preview

ACL-gated preview of PDF (PDF.js), images, text and Markdown without downloading the original.

Dark mode & theming

prefers-color-scheme

A [data-theme] token set with a toggle that respects the OS preference.

Per-user preferences

/api/preferences

Server-side theme, results-per-page and default filters persisted to each account.

Tags & marks

/api/documents

Per-user labels and marks attached to any document, in an independent personal tag space.

Accessibility pass

WCAG 2.1 AA

ARIA live regions, labelled controls, visible focus rings and Escape-to-close on async UI.
